# 解析口令模板（把本文件复制成 backend/data/parse_pass.txt 就是启用口令）
#
# 为什么需要：本项目的「直链解析」是用**站长自己的网盘账号**（BDUSS）出面
# 向百度请求的，所以每被解析一次都消耗站长的账号额度。公网开放后必须加口令，
# 否则等于把账号的解析能力公开出去。
#
# 用法：
#   1. 复制本文件为 backend/data/parse_pass.txt
#      （或改环境变量 ACCEL_PARSE_PASS_FILE 指向别处；
#        注意 backend/data/ 已在 .gitignore 里，口令不会被提交）
#   2. 每行一条口令，改完**立刻生效，不用重启服务**（每次请求都重读文件）
#   3. 请求时带上请求头：X-Parse-Pass: <口令>
#      网页访客版会自动弹窗索要口令，输一次存在浏览器本地。
#
# 行格式：
#   2026-09-13:abc123     只在 2026-09-13 当天有效 —— 过期自动失效
#   abc123                不带日期 = 永久有效
#   # 开头的行             注释，忽略
#
# 建议的日常用法（"每天更新"）：
#   - 每天往文件里**追加**一行 `日期:口令`，比如今天用 `today-9f3k2`
#   - 旧的那些天然过期，不用手动删；想清理就删掉过期行
#   - 想给某个朋友单独一条，就写一行无日期的专用口令，方便按人追溯与吊销
#   - 用量会记录在 accel_pass_usage 表（按口令指纹，不存明文），
#     站长调 GET /api/accel/guest-quota 能看到"今天每条口令各被用了多少次"，
#     哪一条被猛用就删哪一条。
#
# ⚠ 两个必须知道的语义：
#   * 文件不存在或没有任何条目行 → **不启用口令**（退回只按 IP 配额限制）。
#     这是为了让已有部署不被锁死。
#   * 一旦文件里写了条目行，就进入"启用"状态：如果**今天没有有效的行**
#     （例如你忘了追加今天那行），所有访客一律被拒绝 —— 故意做成 fail closed，
#     宁可把朋友挡在外面，也不能因为忘更新就把账号额度敞开。
#
# 环境变量（可选）：
#   ACCEL_PARSE_PASS_FILE  口令文件路径，默认 backend/data/parse_pass.txt
#   ACCEL_GUEST_DAILY      每 IP 每天解析次数上限，默认 20（与口令叠加生效）
#   ACCEL_GUEST=0          整个关掉访客解析
