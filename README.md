# DuPanSou-Archive · 网盘资源聚合搜索引擎

> 个人部署的网盘资源搜索工具，融合 **实时聚合搜索** 与 **历史索引归档**。
> 克隆即用：`python app.py` 打开 `http://localhost:5000`，无需构建前端。

```
        ┌───────────────────────────────┐
        │      DuPanSou-Archive        │
        │   双通道融合网盘搜索引擎       │
        └───────────────────────────────┘
        实时(搜新)  ⚡  +  ⚡ 历史(搜老)
        ┌───────────┐      ┌───────────┐
        │   PanSou    │      │  SQLite   │
        │ 实时聚合搜索 │      │  索引库     │
        └───────────┘      └───────────┘
```

## ✨ 项目亮点

| 能力 | 当年度盘搜 | PanSou | **DuPanSou-Archive** |
|------|:---:|:---:|:---:|
| 历史老资源搜索 | ✅ 强 | ❌ 弱 | ✅ **强** |
| 最新资源搜索 | ❌ 弱 | ✅ 强 | ✅ **强** |
| 死链自动标记 | ❌ | ✅ | ✅ |
| 个人索引积累 | ❌ | ❌ | ✅ **独创** |
| 零依赖部署 | ❌ 需MySQL/ES | ⚠️ 需Go | ✅ 纯Python+SQLite |

核心功能：

- **双通道融合搜索** — 本地 SQLite 索引（毫秒级）+ PanSou 实时聚合（100+ 插件），跨源去重、相关度排序
- **CloudSaver 风格界面** — PC 左侧导航 + 移动端底部标签栏，亮/暗双主题（跟随系统、可切换、防闪烁），vue-router 路由（`/resource` `/douban` `/stats`）
- **🩺 智能链接有效性检测** — 四级有效性状态机（有效 / 疑似失效 / 确认失效 / 未检测）：
  搜索结果自动送检，**失效降权、确认失效自动隐藏**（可一键展开查看）；
  连续 2 次失败才判死（防检测源抖动误杀），用户举报直接确认；
  检测结果按状态保鲜（有效 72h / 疑似 30min / 失效 12h 自动复查是否恢复），磁力/ed2k 等无法检测的类型永不误伤
- **🎬 豆瓣榜单 v2** — 11 个分类（热门电影/最新/冷门佳片/电视剧/国产/欧美/韩/日/动画/综艺/纪录片），
  数据来自豆瓣 v2 榜单接口：大海报 + 左上角评分角标（7.1/10）+ 右上角口碑档（神作/推荐/可看/一般）+
  年份/国家/类型/导演/主演简介行 + 评分人数；排序（默认/评分/上映年份）+ 滚动触底自动加载；
  「豆瓣详情」开条目页、「搜资源」一键转搜索
- **🖼 资源封面双通道** — 影视资源匹配豆瓣海报（标题智能清洗 + 多级降级匹配 + SQLite 永久缓存）；
  非影视资源使用 **TG 频道消息自带图**（PanSou 原生 images 字段，走后端代理解决国内直连问题）；
  图片加载四级链：浏览器直连 → 本地代理（子域轮换重试 + 内存缓存）→ weserv → 首字占位块；
  「封面图」开关记忆偏好
- **同资源聚合分组** — 同一资源的多个网盘/发布帖合并为一张资源卡，其余链接一键展开
- **网盘筛选 chips** — 全部/夸克/百度/阿里/迅雷/115/123/天翼/UC/PikPak/磁力，服务端过滤、计数准确
- **粘贴链接直检** — 搜索框粘贴网盘分享链接，直接返回有效性检测结果
- **分页浏览全量结果** — 完整资源池按页返回（10/20/50 每页可选），结果缓存 5 分钟，翻页零成本
- **点击热度置顶（死链防护）** — 结果点击经 `/api/click` 中转记录，同一关键词下被点过的资源加权置顶；点击瞬间后台智能体检 + 结果卡「失效举报」按钮，确认失效立即撤销热度并打失效标记，死链无法靠点击置顶
- **拼写容错** — Chrome 式"您是不是要找"：搜 `Xmimd` 自动纠正为 `xmind` 重搜并提示（词库取自本地索引+搜索历史，频次防回声污染）
- **书源扩展（学霸盘）** — 内置学习资料/书籍向自定义源，教材/课程/电子书查询自动并发补充检索；`ENABLE_XUEBAPAN` 可开关
- **零结果守望队列** — 搜不到的词自动入队，定时收割器每轮用全源重试，"今天搜不到的教材，有了就有"
- **搜索历史** — 本地记录搜索词，点击重搜、单删、清空
- **渐进式索引** — 每次搜索的实时结果自动入库，定时收割器持续扩充，搜得越多索引越强
- **优先级巡检** — 后台每小时按优先级体检索引库：疑似失效 → 新入库未检测 → 失效复查 → 过期保鲜
- **数据统计** — 网盘分布、热词榜、链接健康、索引增长曲线

## 🚀 快速开始

### 方式一：Docker Compose 一键全栈（推荐）

```bash
git clone https://github.com/caixiaoq/DuPanSou-Archive.git
cd DuPanSou-Archive
docker compose up -d
# 打开 http://localhost:5000
```

### 方式二：手动部署

**1. 启动 PanSou 搜索引擎（前置依赖）**

> ⚠️ 最小命令只监听 1 个默认频道、不启用插件，搜索结果会很少。
> 正式使用请加 `CHANNELS` / `ENABLED_PLUGINS`，完整推荐列表见 [docker-compose.yml](docker-compose.yml)。

```bash
docker run -d --name pansou -p 8888:8888 \
  -e PORT=8888 \
  -e AUTH_ENABLED=false \
  ghcr.io/fish2018/pansou:latest
```

**2. 启动 DuPanSou-Archive 后端**

```bash
cd backend
pip install -r requirements.txt
python app.py
# 打开 http://localhost:5000
```

> 💡 Windows 用户可直接双击根目录的 **`启动服务.bat`**（在独立最小化窗口中运行，
> 关闭该窗口或双击 `停止服务.bat` 即停止）。注意：直接在某终端里 `python app.py`
> 的话，关闭终端窗口服务就会停止。

仓库已自带构建好的前端（`frontend/dist`），克隆后无需 Node 环境。
若修改了前端代码，重新构建：

```bash
cd frontend
npm install
npm run build   # 产物输出到 frontend/dist，Flask 自动 serve
```

开发模式（热更新，可选）：`npm run dev` 后访问 `http://localhost:3000`。

### 默认只监听本机

出于安全考虑，服务默认绑定 `127.0.0.1` 且关闭调试模式。
局域网/服务器访问请显式开放：

```bash
# Windows CMD
set HOST=0.0.0.0
python app.py

# Linux / macOS
HOST=0.0.0.0 python app.py
```

> 🔐 若 PanSou 开启了认证（`AUTH_ENABLED=true`），设置环境变量
> `PANSOU_USERNAME` / `PANSOU_PASSWORD`，后端会自动登录。

## ⚡ 网盘加速（百度网盘直链下载）

侧边栏「网盘加速」：粘贴百度网盘分享链接 → 自动解析直链 → 内置 aria2 多线程下载。
**无需转存到自己的网盘**：使用你自己的登录态（BDUSS）走网页端接口解析，凭证只存本机。

### 使用步骤

1. 进入「网盘加速」页点「📱 扫码登录」，用手机「百度」或「百度网盘」App 扫码即可自动获取凭证（推荐，免复制）；
   也可手动粘贴 `BDUSS` 值或整段 Cookie 请求头（自动提取）；
2. 凭证只存本机 `backend/data/accel.db`，页面只显示尾 4 位；
3. 粘贴分享链接（支持 `?pwd=xxxx` 与「链接+提取码」混排粘贴）→ 解析 → 勾选文件（支持进入文件夹多选）→ 开始下载；
4. 任务区可暂停/继续/删除；直链过期会自动重取并续传。

首次使用会自动下载 aria2c（约 10MB）到 `tools/`（Windows/Linux），也可手动执行
`python scripts/fetch_aria2.py`，或自行安装 aria2（模块会自动从 PATH 识别）。
开发联调可用外部 RPC：设 `ACCEL_ARIA2_RPC=http://127.0.0.1:16800/jsonrpc` 指向 Motrix 等。

### 🔐 安全须知（务必阅读）

- **BDUSS 等于你的百度账号登录态**，拿到它即可操作你的网盘（含转存/删除）。本工具将其保存在本机
  `backend/data/accel.db`（已被 `.gitignore` 排除，不会提交），日志与接口均不输出完整值。
- **保持服务只监听本机**（默认 `127.0.0.1`）。若必须局域网/远程访问，请设置环境变量 `ACCEL_TOKEN`
  并在页面「访问口令」填入相同值，否则加速接口对非本机来源一律拒绝（403）。
- Docker 用户：端口映射请写成 `127.0.0.1:5000:5000`，不要 `-p 5000:5000` 直接暴露公网。
- 不要把 `backend/data/accel.db`、运行日志或含完整响应的截图分享给他人。

### 📶 速度期望

百度对**非会员账号按连接数限速**：多线程（aria2 每文件 16 连接）是把单连接限速×并发数，
实测非会员约 2–6 MB/s × 并发系数。**无法突破账号总限额，不等于会员满速**；
不同地区/运营商/时段存在差异。

## 🧠 核心创新：渐进式索引

**搜得越多，索引越强。**

每次搜索 PanSou 的实时结果会**自动写入本地 SQLite 索引库**；索引库随时间积累，
热门资源的第二次搜索直接命中本地（毫秒级返回）。辅以**定时收割器**（用预设热搜词
定期主动搜索入库）和**链接巡检器**（自动标记失效链接），构成完整闭环。

### 🔒 访客直链解析的访问控制

直链解析是**用站长自己的网盘账号（BDUSS）**出面请求百度的，每被解析一次都消耗账号额度，
所以公网开放时必须设口令。三项限制**叠加**生效：

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `ACCEL_GUEST` | 1 | 设为 `0` 可整个关掉访客解析（只剩本机站长可用） |
| `ACCEL_GUEST_DAILY` | 20 | **每 IP 每天**解析次数上限 |
| `ACCEL_PARSE_PASS_FILE` | `backend/data/parse_pass.txt` | 解析口令文件路径（见下） |

口令文件**每行一条**，改完**立刻生效、不用重启**（每次请求都重读）：

```
2026-09-13:abc123      # 只在当天有效，过期自动失效 —— 每天追加一行即可
friendA-9f3k2          # 不带日期 = 永久有效（适合给某个朋友单独一条）
# 这是注释，空行也忽略
```

* 文件不存在或没有任何条目行 → **不启用口令**（退回只按 IP 配额）；
* 一旦写了条目行，就进入启用状态；**若今天没有有效的行，所有访客一律被拒**
  （故意 fail closed —— 宁可把朋友挡在外面，也不能因为忘更新就把账号额度敞开）；
* 访客请求需带请求头 `X-Parse-Pass: <口令>`；网页访客版会自动弹窗索要，输一次存本地；
* 用量按**口令指纹**（不存明文）记入 `accel_pass_usage` 表，站长调
  `GET /api/accel/guest-quota` 能看到"今天每条口令各被用了多少次"，哪条被猛用就删哪条；
* 模板见 `backend/parse_pass.example.txt`（`backend/data/` 已在 `.gitignore`，口令不会被提交）。

> 更稳的做法：给访客解析单独配一个**小号**（`accel_accounts` 表支持多账号），
> 主号/VIP 只留给自己用 —— 口令挡的是路人，小号分流挡的是"朋友用超量"。

### 🔑 解析口令怎么改

解析口令就是发给朋友的那个"通行证"。**改完立刻生效，不需要重启服务**（后端每次请求都重读文件）。

**方式一：直接编辑口令文件**（默认 `backend/data/parse_pass.txt`，线上部署为 `/app/data/parse_pass.txt`）

```bash
# 追加"今天那行"，日期务必用服务端当天日期
echo "$(date +%F):你今天的新口令" >> backend/data/parse_pass.txt
cat backend/data/parse_pass.txt
```

* **每天换口令** = 追加一行新的；**旧行不必手动删**，日期一过自动失效；
* **给某个朋友单独一条** = 写一行**不带日期**的，例如 `friendA-9f3k2`；不想给了就删掉那一行，不影响其他人；
* `#` 开头的行是注释；
* 想看**今天每条口令各被用了多少次**（哪条被猛用就删哪条）：
  ```bash
  curl -s -H 'X-Access-Token: <你的站长令牌>' http://127.0.0.1:5000/api/accel/guest-quota
  ```
  用量按口令的 sha256 指纹记账，**不存明文**。

**⚠ 两条必须记住的语义**

1. 文件不存在、或没有任何条目行 ⇒ **不启用口令**（退回只按每 IP 配额）。这是为了让已有部署不被锁死。
2. 一旦文件里写了条目行，**若"今天"没有有效的行**（比如你忘了追加今天那行）⇒ **所有访客一律被拒**。
   这是**故意的**（fail closed）：宁可把朋友挡在外面，也不能因为忘更新就把你的网盘账号额度敞开。

> 容器部署时注意**时区**：容器默认 UTC，而你的口令行是按北京时间的日期写的，会导致"写了今天那行却仍被判过期"。本项目部署脚本已给后端容器设置 `TZ=Asia/Shanghai`。

### 🎫 站长令牌怎么用

**站长令牌**（环境变量 `ACCEL_TOKEN`）是你自己的管理员口令，取得站长身份后可读写**全部**设置：
查看/设置/清除 BDUSS、扫码登录、网盘账号池、加速配置、服务器下载与任务管理、修改解析口令、查看口令用量。

**⚠ 绝不能发给任何人** —— 拿到它等于拿到你本人（含你账号的可见性与清除权）。给朋友的是**解析口令**（上一节），两者完全不同。

**怎么在浏览器里用**

1. 打开站点（如 `http://localhost:5000/accel`）；
2. 在「访问口令」输入框里粘贴令牌 —— 输入框失焦即保存到该浏览器的 `localStorage['dps-accel-token']`；
3. 之后这个浏览器一直是站长身份，刷新不丢；换浏览器/清缓存后需重新填一次。

**怎么设置/更换令牌**

```bash
# 本机：启动前设置环境变量
export ACCEL_TOKEN='你的令牌'      # Windows: set ACCEL_TOKEN=你的令牌
python app.py

# Docker：改 compose 里 backend 的 environment 后重建容器
docker compose up -d backend
```

令牌为空时，只有**本机访问**（`127.0.0.1`）算站长 —— 所以本机开发**不需要填令牌**；公网部署**必须设置**，否则远程无法管理任何设置。

**怎么判断请求的站长身份**（排查用）

```bash
# 带令牌应返回 200；不带/令牌错在远程会返回 403
curl -s -o /dev/null -w '%{http_code}\n' -H 'X-Access-Token: 你的令牌' \
     http://127.0.0.1:5000/api/accel/status
```
> 注意：**容器内**看到的来源 IP 是 docker 网关（如 `172.21.0.1`）而非 `127.0.0.1`，
> 所以在服务器上执行 curl **不算"本机站长"**，必须带 `X-Access-Token`。

```
├── backend/          # Python 后端 (Flask + SQLite)
│   ├── indexer/      # ⭐ 历史索引 + 定时收割（核心创新）
│   ├── checker/      # ⭐ 智能链接有效性检测（核心创新）
│   ├── analyzer/     # ⭐ 搜索统计分析
│   ├── search_engine/ # PanSou 适配层
│   ├── accel/        # ⚡ 网盘加速（解析 + aria2，独立模块）
│   └── api/          # REST API
├── frontend/         # Vue 3 前端（dist 已预构建）
├── scripts/          # accel_probe.py 探测脚本 / fetch_aria2.py 下载 aria2
├── tools/            # aria2c 二进制（自动下载，gitignored）
├── downloads/        # 默认下载目录（gitignored）
├── docs/             # 系统设计 / 创新点 / 使用教程
├── docker-compose.yml
└── LICENSE
```
