# 使用教程

> 从零开始搭建并运行 DuPanSou-Archive

---

## 第一步：环境准备

需要安装：
1. **Python 3.9+** — [下载 Python](https://www.python.org/downloads/)
2. **Node.js 18+**（可选，仅开发前端时需要）— [下载 Node.js](https://nodejs.org/)
3. **Go 1.18+**（可选，仅需要自己编译 PanSou 时）— [下载 Go](https://go.dev/dl/)

确认安装成功：
```bash
python --version    # 应输出 Python 3.x.x
node --version      # 应输出 v18.x.x 或更高（可选）
npm --version       # 应输出 9.x.x 或更高（可选）
```

---

## 第二步：启动 PanSou 搜索引擎

DuPanSou-Archive 依赖 PanSou 作为实时搜索引擎后端。

### 方式 A：使用 Docker 启动（推荐）

> ⚠️ 最小命令只监听 1 个默认频道、不启用插件，搜索结果会很少。
> 正式使用请通过 `CHANNELS` 和 `ENABLED_PLUGINS` 指定频道与插件（见 README「启动 PanSou」一节）。

```bash
docker run -d --name pansou -p 8888:8888 \
  -e PORT=8888 \
  -e AUTH_ENABLED=false \
  ghcr.io/fish2018/pansou:latest
```

验证：
```bash
curl http://localhost:8888/api/health
# 应返回 {"status":"ok", ...}
```

### 方式 B：从源码编译

```bash
git clone https://github.com/fish2018/pansou.git
cd pansou
CGO_ENABLED=0 go build -ldflags="-s -w" -o pansou .
./pansou
```

### 方式 C：使用已有的 PanSou 实例

如果已有远程 PanSou 服务，设置环境变量：
```bash
export PANSOU_BASE_URL=https://your-pansou-server.com
```

## 第三步：启动后端

```bash
cd DuPanSou-Archive/backend
pip install -r requirements.txt
python app.py
```

成功启动后输出：
```
DuPanSou-Archive 启动中...
  监听: http://127.0.0.1:5000  (debug=False)
  PanSou 后端: http://localhost:8888
  索引数据库: ...\data\index.db
✅ PanSou 服务在线
  [Harvester] 已启动
  [Checker] 已启动
  索引库: 0 条链接

 * Running on http://127.0.0.1:5000
```

> 默认只监听本机（127.0.0.1）。局域网/服务器部署请设置 `HOST=0.0.0.0`
> （Windows: `set HOST=0.0.0.0`，Linux/macOS: `export HOST=0.0.0.0`）。

## 日常使用

### 搜索资源

1. 在搜索框输入关键词（如"庆余年"、"考研数学"）
2. 按回车或点搜索按钮
3. 结果以**资源卡流**展示：
   - 同一资源的多个网盘/发布帖合并为一张卡，点「同资源其他 N 个链接」展开
   - 每张卡标注来源（实时/历史）与网盘类型，可按网盘过滤
   - 完整结果池分页返回，底部页码条翻页
4. 搜索过的关键词会进入**搜索历史**（搜索框下方），点击可重搜、可删除

### 浏览索引库

点击顶部导航栏的"历史索引"，查看本地索引库中所有积累的链接。
- 支持按关键词搜索索引
- 支持按网盘类型过滤
- 显示链接存活状态

### 查看统计

点击"数据统计"，查看：
- 索引库总量、有效/失效链接
- 各网盘类型分布
- 搜索热词排行榜
- 收割器和巡检器的运行状态

## 高级配置

通过环境变量自定义行为：

```bash
# Windows CMD
set PORT=8080
set HARVEST_KEYWORDS=电影,电视剧,动漫,纪录片
set HARVEST_INTERVAL_HOURS=12
python app.py

# Windows PowerShell
$env:PORT=8080
$env:HARVEST_INTERVAL_HOURS=12
python app.py
```

## 常见问题

**Q: 搜索时显示"无法连接到 PanSou 服务"**
A: PanSou 没有运行。启动方式见第二步。

**Q: 索引库数据太大怎么办**
A: SQLite 支持 140TB 数据量，一般个人使用几年不会有问题。
如果真要清理，删除 `backend/data/index.db` 文件即可重置。

**Q: 前端页面空白 / 提示"前端页面缺失"**
A: 仓库已自带构建好的 `frontend/dist`，正常克隆不会出现此问题。
若你自行删除或改动了前端，重新构建即可：
```bash
cd frontend
npm install
npm run build
```
然后重启 `python app.py`。也可先访问 `http://localhost:5000/api/health` 确认后端已启动。

**Q: 如何更新 PanSou 插件**
A: 从 [fish2018/pansou](https://github.com/fish2018/pansou) 拉取
最新代码，重新编译 PanSou 即可。前端和后端代码无需更新。
