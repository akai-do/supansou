## 2. 导航层级与页面关系

### 2.1 全局导航

- 桌面端：顶部工具栏横向排列，包含外站入口、需求入口和主题切换。
- 移动端：在 `max-width: 768px` 下显示移动菜单按钮，导航收进下拉菜单；需求页样式表中可观察到 768px 与 380px 两个断点。
- 主题：亮/暗模式在所有公开页面共用；状态保存在 `localStorage.alipansou_theme_mode`，根节点类在 `theme-dark` / `theme-light` 之间切换。
- 搜索框：首页居中大搜索框；结果页顶部搜索框回填关键词；需求页顶部保留同一套站点导航。

### 2.2 核心页面关系

```text
首页
  ├── 点击热门/历史/本地词条 -> /search?ai=<词条>
  ├── 输入关键词 + 搜索 -> /search?ai=<关键词>
  ├── 提交需求 -> /demand
  └── 运营位 -> 微信小程序 / 外部链接

搜索结果页
  ├── 点击结果卡片或“获取资源” -> 资源获取弹窗（不跳路由）
  ├── 点击“同名更多结果”编号 -> 同一弹窗切换到另一条资源
  ├── 空结果 -> “登记资源需求” -> /demand
  └── 搜索状态条 -> 取消/停止当前流式搜索

资源需求页
  ├── 提交需求 Tab -> 表单提交 -> 刷新历史需求
  └── 历史需求 Tab -> 列表 -> “想要”投票（公开只读观察到的按钮）
```

### 2.3 关键关系说明

1. **搜索结果没有独立详情路由**。资源详情以弹窗形式呈现，URL 仍停留在 `/search?ai=<关键词>`；弹窗状态不进入路由，刷新后不会恢复弹窗。
2. **“同名更多结果”是同一资源的多个链接变体**，用编号按钮切换，不产生新页面。
3. **需求页是公开页面**，历史需求列表无需登录即可查看；“想要”操作是公开投票行为。
4. **管理后台是独立路由树**，位于 `/admin` 下，需登录；本次未访问，也不在公开功能复现范围内。

## 6. 对本站的架构启示

- 首页承担“搜索 + 快捷发现 + 运营”的三合一职责；本站当前没有独立首页，可考虑增加轻量首页或把快捷发现前置到 `/resource`。
- 搜索结果页的状态条、筛选计数、排序、同名变体是体验差异最大的部分，且都可以在现有 `/resource` 页面上增量实现。
- 资源弹窗是“交付层”，不是“详情页”；本站已有直链/复制能力，建议增加二维码作为补充，而不是改成扫码-only。
- 需求板是独立社区功能，是否建设取决于运营投入；不应为了对标而引入无人维护的表单。
- 管理后台的路由和接口数量说明对方把“内容源、网盘账号、接口配置、搜索排名、需求审核”都做进了同一后台；本站应优先复用现有 Flask 管理能力，而不是一次性复刻全部后台。
