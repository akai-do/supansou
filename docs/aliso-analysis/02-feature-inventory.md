## 8. 功能依赖关系

```text
首页搜索框
  -> 搜索路由
     -> 搜索令牌
     -> 流式搜索
        -> 结果分组
           -> 网盘筛选（计数/多选）
           -> 排序
           -> 资源弹窗
              -> 二维码
              -> 复制分享
              -> 保存网盘/转存
        -> 状态条（数量/类型/耗时/取消）
        -> 空态 -> 需求页

需求页
  -> 需求表单 -> 需求提交
  -> 历史需求 -> 想要投票

全局
  -> 主题切换
  -> 公告/广告
  -> 页脚法律页
```

## 9. 与现有对标文档的关系

`docs/04-aliso公开页面对标与改进规划.md` 已从产品体验角度给出 P0/P1/P2 规划。本清单补充了：

- 公开打包脚本中确认的流式搜索、搜索令牌、资源弹窗、需求接口；
- 公开只读接口的实际响应字段；
- 功能之间的依赖关系；
- 管理后台路由/接口的静态发现（未验证）。

后续实现仍应以本站自己的代码和数据源为基础，不复用对方页面代码、样式、文案或接口。
